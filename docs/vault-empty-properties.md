# 留空的原生 Properties

Vault 读取入口在应用领域默认值和校验前统一处理空属性，规则位于 `tools/vault/properties.mjs`。

- 可选属性的 YAML 空值 / `null` 与省略属性等价。
- 数字、开关、列表、对象、选项等字段的 `""` 与省略属性等价；文本字段的空字符串保留。
- 嵌套对象中的空属性、完全空的对象以及列表中的空白行不进入公开生成物。
- `false`、`0`、有效空列表和非空文本保留，不做真假值转换。
- 关于页图标及文字、番剧进度和观看期间按页面接口补齐必要默认值；未知总集数使用 `0`。
- 有实际内容的字段仍需符合其类型；缺少必填内容、无效日期、重复标识、缺失附件及未配置的加密密码仍阻断发布。
- 私人字段不新增导出路径，原始笔记不被修改。

`tests/content/vault-empty-properties.test.mjs` 覆盖全部受支持的笔记类型及嵌套边界情况。
`tools/vault/fixture.mjs` 在公开源码 CI 中生成同类合成笔记，使 Astro 检查和完整构建同时验证数据适配器与页面接口；不读取私人知识库。
